# Attitude & Disqualification Roleplays

Companion to the experience and driver roleplays (see PR #1). These layer on top of any experience or driver path: the framework spine stays the same, but *how you steer* changes. The disqualification types show how to end a call honestly without burning the lead.

Same conventions: `> [NODE: ...]` marks the framework node, `> CURVEBALL: ...` marks a surprise, and each file ends with improv notes.
