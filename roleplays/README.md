# Setting Call Roleplays

Example setting calls for each prospect type on a futures-trading offer, built on the framework in `../setting framework:script.pdf`.

**These are not word-for-word scripts.** Real calls don't follow the page. Each roleplay shows the *shape* of the conversation, with the curveballs marked so you can practise improvising:

- `> [NODE: ...]` notes tell you which framework node you're in and why.
- `> CURVEBALL: ...` notes mark a place where the lead throws something unexpected.
- Each file ends with **Improv notes** showing how the call could branch differently.

## Fixed spine (same every call)

INTENT → *[middle nodes, order depends on the lead]* → SHOW THE GAP → WANT TO CHANGE / URGENCY → FINANCIAL QUALIFICATION → PITCH → SCHEDULE & LOCK → COMMITMENT TO SHOW UP

## Middle-node abbreviations

| Code | Node |
|---|---|
| PE | Past Experience |
| G | Goal |
| EI | Early Impact |
| CS | Current Situation |
| TL | Timeline |
| WGW | What Got in the Way |

## How to use them

1. Read the **lead profile** at the top, including the hidden truth, and then read the call.
2. Cover the lead's lines and try to answer as yourself. Then compare.
3. Notice where the call *deviates* from the script. That's the point.
4. Pair with someone and run it with the lead's lines changed, say a different budget, a different objection, or a refusal at the gap.

Not covered here: the attitude types (skeptic, tire-kicker, gambler, passive seeker, etc.) and the disqualification types. Those layer on top of any of these.
